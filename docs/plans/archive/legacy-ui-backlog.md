# Legacy UI Backlog

This document preserves plans deferred before the post-meeting operational review. These items are reference material, not active delivery commitments.

## Phase 2B: Reusable UI Extraction

- Evaluate shared table shells for repeated desktop and mobile list layouts.
- Evaluate reusable stat cards, empty states, form fields, and destructive actions.
- Consolidate remaining page-local modal patterns only where reuse reduces maintenance cost.
- Continue visual normalization on low-use administration and reporting pages.

Phase 2A already established semantic status badges, action hierarchy, typography, contrast, radius, and spacing. Any future extraction must preserve those semantics and must not require Phase 2B for a page to remain complete.

## Deferred Visual Review

- Review Director pages one screen at a time.
- Identify information that should be retained, condensed, relocated, or removed.
- Keep each approved screen adjustment in an independent commit.
- Do not perform broad Director layout changes without product review.
